# 운동해듀오 본선 발표 장표

건강증진 아이디어 경진대회 본선 발표(10분)용 장표다. reveal.js 위에 직접 짠 HTML과 CSS로 만들었고 화면은 1920×1080이다.

- 열기: `index.html`. 로컬에서는 폴더를 웹 서버로 띄워 연다(글꼴을 불러오려면 필요하다).
- 넘기기: 오른쪽 화살표나 스페이스. 장을 넘기면 그 장의 움직임이 짧은 간격으로 이어서 모두 나온다.
- S: 발표자 노트 창. E: 지금 장을 끝 모습으로. R: 지금 장을 처음부터 다시.
- `?final`을 붙이면 모든 장이 움직임 없이 끝 모습으로 열린다.
- `?narr`를 붙이면 장마다 내용이 나레이션 길이에 맞춰 차례로 나온다.
- 16장 시연 영상: `media/demo.mp4`에 넣는다. 다른 이름이면 `index.html` 맨 아래 `DEMO_VIDEO` 한 줄만 바꾼다.
- 틀은 하나다. 모든 장이 머리줄, 큰 머리말, 설명 한 줄, 본문, 출처 순서로 같은 위치에 놓인다. 본문 그림은 큰 숫자 카드, 가로 막대, 단계 칸, 인용 카드 넷만 쓴다. 서식은 `css/deck.css`에 있다.

글꼴 Pretendard(SIL OFL 1.1)와 reveal.js(MIT)는 `vendor/`에 원본 라이선스와 함께 넣었다.
